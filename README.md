## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/singhtanya05/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📁 Project Structure

```
portfolio/
├── src/
│   ├── assets/         # Static assets
│   ├── components/     # Reusable components
│   ├── pages/         # Page components
│   ├── styles/        # Global styles
│   ├── App.tsx        # Main App
│   └── main.tsx       # Entry point
├── public/            # Public assets
└── config files       # Configuration files
```

## 🎨 Customization

### Personal Information
Update your details in:
- `src/pages/Home.tsx` - Personal info
- `src/assets/photo.jpg` - Profile picture
- `public/resume.pdf` - Resume

### Styling
- Modify `tailwind.config.js` for theme
- Update `src/styles/globals.css` for global styles
